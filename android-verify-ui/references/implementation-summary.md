## 9. 最终结论

- `PASS`：真机截图与 Figma/参考截图的视觉比对通过，且适用的必需 A11y 验收完成。
- `STATIC_ONLY`：仅静态视觉或 A11y 检查完成，不得表述为实机、设计一致或动态无障碍通过。
- `SKIPPED_NO_UI`：需求与 diff 均无 UI 影响，UI Skill 不适用。
- `BLOCKED`：存在 UI 影响但没有任何可执行验证路径。
